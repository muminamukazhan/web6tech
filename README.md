## Description

A multi-page website with jQuery tasks: selectors, effects, DOM manipulation, animations and a mini project (Image Gallery with NaNa Official Arts).

## Pages

- index.html — Home
- task0.html — Setup ($(document).ready, console message)
- task1.html — Selectors & CSS (.text(), .html(), .css())
- task2.html — hide, show, toggle
- task3.html — fadeIn, fadeOut, fadeToggle
- task4.html — slideUp, slideDown, slideToggle
- task5.html — append, prepend, remove
- task6.html — attr(): image src and link href
- task7.html — live form with .val() and .text()
- task8.html — basic .animate()
- task9.html — sequential animations
- task10.html — combined animation
- task11.html — Image Gallery

## How to run

1. Clone the repository.
2. Put your pictures into the images folder as nana1.jpg ... nana8.jpg.
3. Open index.html in a browser or use the GitHub Pages link.
